# Инструкция координатора (COORDINATOR) — «ЦЕЗАРЬ»

Роль **Координатор** — работа поперёк всех рабочих пространств: агрегированный
дашборд группы «Координаторы», видимость и редактирование сущностей во всех
подразделениях, помощь руководителям. Без управления пользователями и ролями
(это зона администратора).

---

## 1. Вход и главная страница

Вход через Яндекс ID. После входа доступен **агрегированный дашборд**: сводка по
всем пространствам — задачи, проекты, совещания, гранты и т.д. с фильтрами по
подразделению, статусу, приоритету, сроку.

## 2. Что доступно координатору

| Возможность | Комментарий |
|---|---|
| Видеть все сущности всех пространств | Включая нерасшаренные — пространство не изолируется от координатора |
| Создавать/редактировать в любом пространстве | В форме создания **можно выбрать любое пространство** (руководителю — только своё) |
| Управлять составом и модулями любого пространства | Как руководитель — через «⚙️ Администрирование» |
| Назначать роли в пространстве (HEAD/MEMBER) | Но **не глобальные** роли (ADMIN/COORDINATOR меняет только админ) |
| Шеринг сущностей между пространствами | READ / EDIT / FULL |
| Telegram/Календарь — область «вся система» | Сводки по всем подразделениям |

Инварианты, которые проверяются системой и при понижении роли:

* в каждом подразделении должен остаться хотя бы один руководитель (HEAD);
* не более одного ответственного от каждого участвующего подразделения.

## 3. Типовые операции

**Создать задачу руководителю в его пространстве:** раздел «Задачи» → «+» →
в селекте пространства выбрать нужное подразделение → заполнить карточку.

**Перенести человека между пространствами:** «⚙️ Администрирование» нужного
пространства → «Участники» → добавить; в старом — исключить.

**Включить модуль пространству:** «⚙️ Администрирование» → «Модули» → тумблер.

**Расшарить сущность между отделами:** на карточке → «Поделиться» → выбрать
отдел-получатель и уровень (READ/EDIT/FULL).

## 4. Отличия от администратора

Координатор **не может**: создавать/deактивировать пользователей, менять глобальную
роль (admin/coordinator/member), создавать новые подразделения, управлять
приглашениями, видеть системные настройки. При необходимости — к администратору
([INSTRUCTION_ADMIN.md](INSTRUCTION_ADMIN.md)).

## 5. Частые ситуации

| Ситуация | Решение |
|---|---|
| Не открывается вкладка общей админки (`/admin`) | Это зона ADMIN, обратитесь к администратору |
| Понижение HEAD не применяется | Система требует оставить в пространстве другого руководителя |
| Руководитель жалуется на «чужое пространство» | Проверьте членство пользователя в этом пространстве («Участники») |
