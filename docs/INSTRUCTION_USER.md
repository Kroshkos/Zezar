# Инструкция пользователя (Участник) — «ЦЕЗАРЬ»

Роль **Участник (MEMBER)** — базовая роль сотрудника рабочего пространства
(подразделения). Полный текст руководства — в [USER_GUIDE.md](USER_GUIDE.md),
здесь — краткая прикладная инструкция.

---

## 1. Вход в систему

Регистрация закрыта. Аккаунт создаёт администратор по вашему Яндекс-аккаунту
(или выдаёт приглашение).

1. Откройте адрес сервиса → **«Войти через Яндекс ID»**.
2. Подтвердите доступ в Яндексе — вы попадёте на **Дашборд** своего пространства.
3. Видите «Доступ закрыт»? Обратитесь к администратору, затем войдите заново.

Выход: аватар в правом верхнем углу → **Выйти**.

## 2. Что доступно участнику

| Раздел | Возможности |
|---|---|
| 📊 Дашборд | Свои задачи, ближайшие совещания, статусы |
| ✅ Задачи | Создавать поручения, вести свои карточки, менять статус |
| 📁 Проектная работа | Создавать проекты, работать над своими этапами |
| 🤝 Совещания | Создавать встречи, видеть свои и подразделенческие |
| Дополнительные модули* | Документы, ПО, Гранты, Стипендии, Приоритеты — если включены руководителем |

\* Набор модулей вашего пространства и права на них настраивает руководитель.

**Недоступно:** администрирование подразделения, приглашение людей, включение
модулей, расшаривание сущностей на другие пространства, выбор чужого пространства.

## 3. Работа с задачами и проектами

* Кнопка **«+»** в разделе — создание карточки. Пространство подставляется
  автоматически (ваше подразделение). Если вы состоите в нескольких
  подразделениях, в форме можно выбрать любое из **своих** — новая карточка
  создастся в выбранном пространстве. Чужое пространство выбрать нельзя —
  это привилегия координатора/админа.
* У карточки задаются: название, описание, статус, приоритет, срок, теги,
  ответственный (из сотрудников вашего пространства).
* Поиск — строка сверху; фильтры — по статусу/приоритету.
* Изменения сохраняются на сервере сразу.

## 4. Ответственные и уведомления

* По одной сущности может быть **не более одного ответственного от каждого
  участвующего подразделения** — это правило системы.
* Telegram: привяжите аккаунт (профиль → интеграции, бот `/start <код>`), и вы
  будете получать уведомления о создании/редактировании/смене статуса и о
  назначении вас ответственным. Команды бота: `/tasks`, `/mute`, `/unmute`.
* Яндекс.Календарь: при подключении app-пароля ваши задачи и совещания
  автоматически синхронизируются в личный календарь «Цезарь».

## 5. Частые ситуации

| Ситуация | Что делать |
|---|---|
| «Доступ закрыт» при входе | Попросить админа добавить аккаунт/приглашение |
| Нет нужного раздела в сайдбаре | Руководитель не включил модуль — попросите включить |
| Не назначается ответственный из другого отдела | Назначьте ответственного от своего подразделения, остальное — через руководителя |
| Задача видна другому отделу | Так и задумано, если сущность расшарена руководителем (READ/EDIT) |
