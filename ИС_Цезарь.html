Модуль «На блоке / стопе»

Отдельный обзор задач, работа по которым остановлена. На основной доске эти задачи подсвечены, но не обязаны занимать колонку — здесь собран весь список с причинами блокировки для еженедельного разбора.

Печать карточек для физической доски

А4 (альбомная) — 6 карточек на лист (3×2); А3 (альбомная) — 12 карточек на лист (4×3). Печатаются либо задачи, отмеченные в реестре, либо все под текущим фильтром — если ничего не отмечено. QR-код печатается только при наличии ссылки на Яндекс.Диск.

Справочник направлений

Единый список тегов направлений — используется во всех выпадающих списках карточек, чтобы избежать разночтений в командной работе.

Реестр исполнителей

Единый список сотрудников/ролей — общий для канбана и календаря. На карточке можно указать до нескольких исполнителей с разными ролями (головной, соисполнитель, помощник, контролирующий).

Карточка совещания

Данные о задачах подтягиваются напрямую из системы «Канбан + Календарь», если она открыта в этом же браузере — изменения синхронизируются сразу. Иначе работайте по последнему импортированному JSON-экспорту канбана.

1. Статусы имеющихся задач

Выберите задачу по ID или названию из выпадающего списка — карточка подтянется автоматически со всеми полями. Внесённые изменения статуса/причины сразу применяются к задаче в канбане и, при необходимости, к связанному событию в календаре.

2. Новые задачи (заведены на совещании)

Упрощённая форма — название, срок, исполнитель, направление. Остальные поля (чек-лист, вложения, ссылка на Диск) дозаполняются позже прямо в канбане.

3. События календаря (отсутствия, командировки, мероприятия)

Укажите название мероприятия и отметьте, кого из реестра сотрудников оно касается (можно нескольких).

4. Инсайты

Укажите формат — идея, мероприятие или лайфхак. Если есть привязка к конкретной задаче — выберите её по ID; если нет, запись уходит в общий банк инсайтов для разбора на будущих планёрках.

Итог

Печатный бланк для ведения совещания на бумаге

Бланк формируется с готовой повесткой: задачи, которые должны были быть выполнены на этой неделе, и задачи/мероприятия, запланированные вперёд. Поля для отметок остаются пустыми — печатный вариант нужен только для удобства ведения совещания вручную, заполненный вариант печатать не требуется.

Банк инсайтов

Все инсайты без привязки к задаче копятся здесь для разбора на еженедельных планёрках — чтобы не залёживались. Отмечайте разобранные, чтобы держать банк актуальным.
